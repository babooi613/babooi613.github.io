Privacy Policy

Last updated: November 11, 2026

This app is a personal Rakazo assistant that runs on its owner's own computer and is used only by its owner.

What data it accesses

With the owner's permission through Google sign-in, the app accesses the owner's Gmail account to read, search, label and draft email when the owner's assistant is asked to.

How the data is used

Gmail data is used only to carry out the owner's own requests. It is not sold, shared with third parties, or used for advertising.

Where the data is stored

Sign-in tokens and any data the assistant handles stay on the owner's own computer. Requests may be processed by the AI model provider the owner has configured in Rakazo.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
